# Titanic Dataset Analysis

This project performs data analysis on the Titanic dataset using:

- NumPy
- Pandas
- Matplotlib

## Tasks Performed

### NumPy
- Array creation
- Mean, median, max, min
- Standard deviation
- Reshaping arrays
- Array slicing
- Mathematical operations

### Pandas
- Loading Titanic dataset
- Dataset information
- Filtering data
- Handling missing values
- Passenger analysis

### Matplotlib
- Bar chart
- Pie chart
- Histogram
- Scatter plot

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib

## Dataset
Titanic Dataset (`titanic.csv`)
